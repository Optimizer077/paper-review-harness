01 / THE FRAMEWORK

Read the whole argument.
Inspect the critical joints.

One catalog, adapted to the contribution. Each rating has a concrete anchor, an evidence location, and a reason another reader can inspect.

01

Make the claim recoverable.

Identify the question, the actual contribution, and the conditions under which an answer would hold. Novelty and usefulness are separate claims.

02

Follow the evidence all the way.

Trace claims to results, proof steps, tables, or inspected source passages. Record what is unverified. An evidence field is a record, not verification.

03

Revise the weakest link.

Keep missing checks, observed defects, and uncertainty separate. Resolve the cause of a cap instead of polishing around it.

03 / TRANSPARENT SCORING

An average is a start.
A weak link sets the limit.

Aggressive mode is the default here. It preserves the raw anchored score, then applies the lowest triggered cap. Penalties are never added together.
